# Security policy

This repository holds the source of the www.assetas.com marketing website. It's a static site on GitHub Pages: no accounts, no logins and no server code. The contact form posts to Web3Forms.

## Reporting a vulnerability

Report it privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability** (https://github.com/Assetas/Website/security/advisories/new). Please don't open a public issue or pull request for a security problem.

Include the affected page or file, what you found and the steps to reproduce it. We'll acknowledge the report and keep you updated until it's resolved.

## Scope

In scope: this repository, its GitHub Actions workflow, and the site it publishes (https://assetas.github.io/Website/ and, once live, www.assetas.com).

Out of scope: the Assetas platform and Trek apps (contact Assetas directly), Web3Forms and GitHub Pages themselves, and reports from automated scanners with no demonstrated impact.
